
# Códigos de status HTTP

Os códigos de status HTTP indicam o resultado de uma requisição HTTP.

As principais categorias são:

- 1xx: informações.
- 2xx: requisição processada com sucesso.
- 3xx: redirecionamento.
- 4xx: erro associado à requisição do cliente.
- 5xx: erro durante o processamento no servidor.

Códigos comuns:

- 200 OK: a requisição foi processada com sucesso.
- 201 Created: um recurso foi criado com sucesso.
- 204 No Content: a requisição foi processada com sucesso, sem conteúdo na resposta.
- 400 Bad Request: a requisição é inválida.
- 401 Unauthorized: a requisição exige autenticação válida.
- 403 Forbidden: o servidor recusou a operação por falta de permissão.
- 404 Not Found: o recurso solicitado não foi encontrado.
- 500 Internal Server Error: ocorreu um erro interno no servidor.
- 503 Service Unavailable: o serviço está temporariamente indisponível.
