# REST e APIs REST

REST significa Representational State Transfer.
É um estilo arquitetural utilizado para projetar sistemas
distribuídos que se comunicam por meio de recursos.

APIs REST normalmente utilizam HTTP para permitir que
clientes consultem ou alterem recursos.

Métodos HTTP comuns:
- GET: consulta um recurso.
- POST: cria um recurso ou solicita uma operação.
- PUT: substitui um recurso existente.
- PATCH: altera parcialmente um recurso.
- DELETE: solicita a remoção de um recurso.

Uma API REST pode representar recursos em JSON.
Por exemplo, GET /users/10 pode retornar os dados
do usuário de identificador 10.

REST não significa residência. A sigla significa
Representational State Transfer.
