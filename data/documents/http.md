
# HTTP e métodos de requisição

HTTP significa Hypertext Transfer Protocol. É um protocolo utilizado para a comunicação entre clientes e servidores na web.

Uma requisição HTTP contém um método, um caminho e, opcionalmente, cabeçalhos e um corpo.

Os métodos HTTP indicam a operação pretendida sobre um recurso.

- GET: solicita a representação de um recurso.
- POST: envia dados para processamento ou criação de um recurso.
- PUT: substitui a representação de um recurso.
- PATCH: solicita uma alteração parcial de um recurso.
- DELETE: solicita a remoção de um recurso.

Os métodos GET são normalmente utilizados para consultar informações. Em APIs, o corpo de uma resposta pode conter dados em formato JSON.

HTTP é um protocolo de comunicação. REST é um estilo arquitetural que pode utilizar HTTP.
